# 普通账号本地发布

双击项目目录的 `ordinary-run.cmd`。它会列出本批次的账号、视频、标题和发布设置；只有输入终端提示的 `PUBLISH 数量` 才会真实上传并公开发布。输入其他内容取消。没有待发视频时直接结束。

## 当前单账号测试

当前测试账号的 `test1.mp4` 已发布并记录在账本中，再运行会跳过它。2026-09-17 用户明确要求重发同一视频后，已通过正式入口额外公开发布 1 条，并核对内容管理页“已发布”。原记录保留，重发记录包含独立授权及来源记录；规划器不会自动重复使用素材。

1. 把新视频放在本机目录。正在复制的视频至少静置 60 秒。
2. 在 `config/ordinary-account.local.json` 修改该账号的 `materialFile`，填写新视频完整路径；`materialDir` 必须包含这个文件。默认标题取文件名。
3. `dailyTarget` 是每个账号当日累计目标，包含已发布和待审作品。如果当天已有 1 条，想再发 1 条，就把目标设为 2，并确保 `maxAttemptsPerDay` 至少为 2。不要删除历史账本。
4. 双击 `ordinary-run.cmd`，核对清单后确认。

`materialFile` 表示只取指定文件；删除这个字段才会扫描整个 `materialDir`。素材按内容去重，单纯改文件名不会绕过去重。

## 登录与账号核对

当前单账号可双击 `ordinary-login.cmd`。自行扫码后在终端按 Enter；脚本会保存本机会话，再从创作者首页核对实际抖音号。该登录入口不会选择素材或发布。

已有保存的会话时，只读复核命令为：

```powershell
node src/cli.mjs verify --config config/ordinary-account.local.json --account ordinary-test
```

账号不一致、需要重新登录或页面控件发生变化时会停止。平台如果要求验证码，需要本人在浏览器完成；没有验证码绕过功能。

## 多账号配置

复制 `config/ordinary-accounts.example.json` 为 `config/ordinary-accounts.local.json`，逐个填写稳定账号代号、真实抖音号和本机素材目录。示例两个账号指向同一个 KOC 目录；也可以分别配置不同目录。每个账号只会发布尚未使用的素材。

分别登录，每次浏览器只登录当前指定账号：

```powershell
node src/cli.mjs login --config config/ordinary-accounts.local.json --account account-a
node src/cli.mjs login --config config/ordinary-accounts.local.json --account account-b
```

预览并运行：

```powershell
.\ordinary-run.cmd --config config/ordinary-accounts.local.json
```

多账号顺序运行，登录态和去重记录按账号隔离。当前完成了单账号真实发布及正式入口的授权重发验收；多账号真实联调及星图任务绑定还需要用相应账号验收。

## 查看结果

```powershell
node src/cli.mjs report --config config/ordinary-account.local.json
```

在配置的 `dataDir` 查看 `last-report.json`、`ledger.json` 和 `screenshots/`。新的创建接口回执只表示平台接收投稿，因此脚本记为 `PENDING_REVIEW`。在平台确认“已发布”或明确驳回后再标记审核结果。

出现 `UNKNOWN`、`RUNNING` 或 `SUBMITTING` 时先去平台核对，不能直接清空账本或再次发布。同一批次确认后，如果账号、素材、标题、页面设置或账本被修改，入口会要求重新预览，避免发布的内容与确认内容不一致。

配置已根据 2026-09-17 实测页面校准；网页更新可能使定位失效，此时会停止而不会盲点其他控件。成功回执依据实际点击后该页发出的创建请求和唯一作品编号，不以旧作品卡片或草稿判断成功。

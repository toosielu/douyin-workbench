# 普通账号网页工作台

启动命令（CMD）：

```cmd
cd /d D:\Projects\douyin-workbench
ordinary-workbench.cmd
```

保持终端运行，把终端打印的完整网址（包含 # 后的会话串）复制到浏览器。此入口复用 `config/ordinary-excel.local.json` 和原普通账号账本；旧的 `workbench-demo.cmd` 是模拟入口。

1. **文案与素材**：选择 `.xlsx` 文案库，或填入本机 Excel 完整路径。选择文件仅复制到本机程序目录，最大 650 KB；更大文件使用路径。Excel 列名：`文案编号`、`文案内容`、`是否启用`，是否启用填写“是”或“否”。
2. 素材目录填 `D:\素材\剪辑师\2026-09-17` 这样的视频所在目录，点击**保存资料**。请先添加自己的账号并核对身份。页面保留账号原有内部编号和身份，不创建新别名。
3. 点击**扫描并预览**，逐条查看账号、视频、正文。文件名须为 `剪辑师_类型_序号_KOC.mp4`。只扫描该目录直接文件，跳过子目录、重复内容和未完成写入的文件。
4. 点击**发布本轮视频**，在确认框确认真实投稿。系统使用预览中固定的完整文案，不再重新随机抽取。已有登录态会复用；失效时在页面打开账号登录并完成核对。
5. 投稿收到唯一平台回执后，移入原目录的 `已发_KOC名称`，例如 `已发_KOC1`。记录区显示回执、完整文案和归档路径。归档失败使用**补归档（不重发）**。

文案格式：

```text
这一段先替你录下来，有空的时候一起听听。
#牙膏#生活碎片#好好生活
fzq_A_3
```

**停止后续发布**会让当前条目执行完，再取消未开始的条目。结果不明会保留记录并阻止自动重试，需要先在抖音核对。流量减少提示不影响回执判断，也不会导致自动重发。已接收不等于审核通过。

这是素材驱动的普通账号入口，不按旧 CMD 的每日数量目标补齐；星图任务关联不在此入口实现。

## 账号库与映射

支持 **Excel 批量导入账号**：展开导入区域，下载模板，填写 `.xlsx` 后点击“校验并预览账号”，检查新增/更新结果，再点击“应用到账号表单”，最后“保存资料”。导入不会自动登录或发布。

六列表头为：`抖音号`、`负责运营`、`剪辑师代号`、`KOC`、`素材目录`、`是否启用`。是否启用填“是/否”，抖音号必须以文本格式输入。模板第 2 行是默认停用的示例，使用前替换或删除。最多 200 条，上传不超过 650 KB；表名使用“账号库”，或仅保留一个工作表。

相同抖音号更新映射并保留原内部编号和登录状态，未出现在 Excel 中的已有账号保留。重复账号、缺少字段、公式和数值格式的抖音号会拒绝导入，修正后再试。

在“基础资料 → 账号库与映射”中新增账号。填写：真实抖音号、负责运营、剪辑师代号、KOC、视频所在目录和启用状态。在“本机当前运营”中填写本机使用者的运营名称，需与账号记录中的负责运营完全一致。

例如：视频 `fzq_A_4_KOC1.mp4` 的匹配条件为剪辑师 `fzq`、KOC `KOC1`。账号目录填视频所在的日期目录，不是所有剪辑师的总根目录。只有当前运营负责且启用的匹配账号可以分配；同一 KOC 对应多个可用账号时随机选一个，预览后固定。同一内容在一次扫描中只领取一次。

保存后，在“账号登录与身份核对”中选择账号并扫码。各账号的登录状态单独保存在本机，不会共享 Cookie；页面的“已核对”只表示本机保存过核对结果，不代表在线会话永远有效。

已有账号不能更换抖音号或删除，请停用以保留历史。新增账号由系统分配稳定内部编号。两处页面同时修改时，旧配置会拒绝覆盖新配置，需重新打开终端的完整地址再编辑。

旧配置在补齐并保存映射前，仍使用原来的按目录分配方式；页面会显示提示。保存映射不会自动发布、移动视频或清空历史。

此版本仍是本机账本：不支持多台运营电脑在共享目录中并发领取。客户的统一协调服务或共享账本试点须单独实现并验收，不能直接把各电脑的配置指向同一个共享盘就当作多人部署完成。

启动、保存和预览都不会自动投稿。当前三个测试视频已经归档，因此扫描为 0 时请放入新的未发素材，不要为了测试把已发视频搬回来。

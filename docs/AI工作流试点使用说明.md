# AI 工作流试点

源码工作台新增“AI 生成发布计划”。保留左侧布局和已有真实发布确认。此版本未替换已安装客户端。

## 模型配置

使用支持 Chat Completions、JSON object 响应的 HTTPS 接口。在启动源码工作台的同一个 PowerShell 会话设置：

```powershell
$env:DOUYIN_AI_URL = 'https://你的服务地址/v1/chat/completions'
$env:DOUYIN_AI_MODEL = '你的模型名称'
$aiSecret = Read-Host '模型 API Key' -AsSecureString
$env:DOUYIN_AI_KEY = [System.Net.NetworkCredential]::new('', $aiSecret).Password
node src/ordinary-workbench-main.mjs --config "配置文件的完整路径"
```

URL 必须是完整接口地址，不仅是基础域名。凭证不写入项目、浏览器或日志；仅在本机进程环境中使用。退出后可执行 `Remove-Item Env:DOUYIN_AI_KEY` 清除本 PowerShell 中的变量。不要把凭证发到聊天。修改环境变量需重新启动相应程序才会生效。

不要同时启动两个使用同一数据目录的工作台。安装版升级及服务重启需另行确认。当前没有真实模型凭证，因此已验证的是模拟响应和本地集成，尚未验证具体服务兼容性。

## 操作

1. 保存账号映射、当前运营、素材目录和 Excel 文案库。
2. 输入例如“选择 KOC3 的素材，搭配生活记录类文案，生成预览”。
3. 阅读并勾选资料发送确认，点击“AI 生成预览”。
4. 核对账号、视频、文案、选择理由及未选原因。
5. 点击已有“发布本轮视频”，确认真实发布。程序保留发布回执并归档。

AI 基于规则扫描后的候选做筛选和选文案；账号由现有剪辑师/KOC映射确定。AI 不更换账号、不读取视频、不编写新文案、不调整映射、不绑定星图任务。缺少客户/产品等资料时应返回说明，不凭空推断。后续需另行加入业务资料结构。

只向配置服务发送本轮指令、候选文件名、剪辑师/KOC和启用文案；不发送视频、完整目录、抖音号码、Cookie或发布历史。指令本身可能包含敏感内容，请避免填写凭证。此操作每轮一次模型请求，45秒超时、不自动重试；最多100条候选、200条文案及10万字符上下文。模型费用按实际服务计费，本版未提供月度费用统计。

预览不写投稿记录、不自动发布。错误或格式不合法会清空本轮预览；修改配置/记录后必须重新生成。模型输出仍需要人工核对；“已接收”不等于平台审核通过。

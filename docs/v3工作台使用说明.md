# v3 本地发布工作台

依据《项目方案_v3.md》实现的首版本地工作台。新主线以当天素材为起点，不再按账号凑每日 9 条、不强制三个任务覆盖、不自动对驳回作品补发。旧 demo/ordinary 入口保留作历史测试工具，不代表新业务规则。

## 立即体验

双击项目根目录 `workbench-demo.cmd`，打开终端打印的完整本机网址。先点“扫描并预览”，再点“开始本轮模拟”。页面包括素材匹配、文案与标签、任务候选、进度、结果和恢复入口。

自动生成的示例文件仅供流程测试，并非可播放或可发布的视频。模拟运行不连接抖音、不移动原文件，使用 `.douyin-v3-simulation` 独立台账。再次扫描会跳过模拟已用内容；演示运行结果会保留。启动依赖现有 Node.js 24；本轮没有安装新的依赖。

## 配置真实资料

复制 `config/workbench.example.json` 为 `config/workbench.local.json`，填写实际绝对路径、运营与映射。然后运行：

```powershell
.\workbench.cmd config\workbench.local.json
```

素材层级是 `root/剪辑师目录/YYYY-MM-DD/文件名.mp4`。剪辑师目录名由 editors.folder 配置，文件前缀与 editors.id 一致。例如 `剪辑师一/2026-09-17/fzq_LONG_3_佳佳.mp4`，KOC 为“佳佳”，文案末尾追加 `#fzq_LONG_3`。type 可多字符；首版严格四段，不猜测下划线内嵌、别名或旧格式。只扫描当天目录中的直接视频文件，已发目录不参与。

accounts 必须包含运营 operatorId、稳定账号代号 id、真实抖音号 expectedIdentity、KOC、剪辑师及 enabled。同一 KOC 可以有多个账号，程序仅从当前运营负责的启用账号中随机选择。未知投稿按真实抖音号隔离，改账号代号不能绕过。

## 导入

工作台支持 JSON 数组与 UTF-8 CSV，先校验预览、应用到草稿，再保存。导入是替换对应资料库，其他配置保留；不是静默追加。

| 库 | 必须字段 |
|---|---|
| 账号 | id,expectedIdentity,operatorId,koc,editor,enabled |
| 任务 | id,name,enabled |
| 文案 | id,text,enabled |

CSV 的 enabled 使用 true/false；逗号或换行文本用双引号包围，双引号写成两个双引号。JSON 的 enabled 必须是布尔值。任务库/文案库统一；禁用任务不会进入候选列表。文案与任务分别随机选取，任务以页面核对可选性后的结果为准。

Word/Excel 的原始样例尚未提供，当前没有宣称支持任意 Word/Excel 直接导入。先用上述明确字段交换资料，收到真实样例后再增加对应解析器。

## 真实发布前

真实模式需要 `mode: live`、本机 `authDataDir`、已校准的任务页面 `uiFile`。工作台账号登录按钮会打开对应账号的独立浏览器，扫码后点“已完成登录，核对并保存”。身份不匹配不保存为可发布会话。

真实任务 profile 还必须校准描述区、任务列表、精确任务 ID 与绑定结果及发布设置。`config/workbench-task-ui.example.json` 保留明确占位符，会在任何上传前阻断；不能直接把 evidence 改成 live_verified 当作校准。历史普通账号发布成功不代表星图任务绑定已经验收。

每轮先预览，真实发布弹出确认。平台要求本人验证时，浏览器保留，工作台显示等待验证。验证后只观察页面继续原请求，不再点击发布；若两分钟仍无法取得唯一回执则记 UNKNOWN，相关账号后续停止，需要核对。没有绕过验证码功能。

## 状态与恢复

- 平台接收并取得唯一作品编号后：素材 USED，投稿 ACCEPTED，审核 PENDING；立即归档到原日期目录的 `已发_KOC`。
- 归档不覆盖已有文件。移动使用复制、哈希核对、删除源文件；失败保留 USED，点“补归档”仅处理文件。
- UNKNOWN、提交中断：禁止自动重发；先在平台核对，在工作台填写结果和依据，已接收必须填写唯一作品编号。
- 明确未提交的准备失败：保留记录，人工核对为未提交后才重新进入下一轮。
- 没有可选任务：本轮跳过，不换账号；明确未提交的预占会在下一轮释放。
- 停止后续发布：当前作品先取得结果，尚未开始的预占取消。新加入素材在下次扫描时处理。

状态不会自动跟随平台后续审核；驳回不恢复素材资格。运行进度显示当前进程，崩溃时的 RUNNING/SUBMITTING 等会作为历史待处理记录显示，不自动重试。

## 多人及共享盘边界

真实模式统一台账固定在素材根目录 `.douyin-v3/ledger.json`，排他锁为 `.douyin-v3/run.lock`。所有工作台必须使用同一完整素材根与同一共享协调目录，不得每人复制一份台账。当前简单实现串行占用整个共享根，优先保证唯一领取，不是并行调度系统。

共享 UNC 默认禁止，部署时需明确授权后设置 allowNetwork=true，并验证创建锁、原子写台账和复制删除权限。服务只监听 127.0.0.1；访问令牌仅用于本机工作台会话。不要把会话目录、真实配置或访问地址分享给其他人。

本轮只在本机临时目录测试多人抢占，没有连接公司内网，也未验证实际 SMB/NAS 锁与故障语义。异常退出后不要直接删除 run.lock；先确认无其他执行进程、核对平台投稿，再由维护者处理过期锁。

## 本轮验证与限制

110 项新旧离线测试、新增 2 项任务页面浏览器模拟测试通过；本地浏览器完成两条模拟、重复扫描去重、宽窄布局检查，页面错误为 0。测试归档使用隔离临时目录，不改动客户素材。

已实现本地工作台、JSON/CSV 导入、当天扫描、映射与随机文案、全局内容去重、任务候选过滤、串行状态、归档与异常恢复。真实星图选择器、公司共享盘与 Word/Excel 资料格式仍需客户样例联调。快照批次和无可选任务时跳过，当前作为首版明确假设，仍可按客户后续决定调整。

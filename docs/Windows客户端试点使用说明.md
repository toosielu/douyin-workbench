# Windows 客户端试点

本版面向单运营、本地素材的普通账号试点。不是多人内网共享正式版；星图关联和内网素材领取服务尚未接入。

## 安装与使用

1. 安装 `dist/desktop/DouyinWorkbench-0.1.0-x64-Setup.exe`，双击桌面“抖音发布工作台”。无需安装 Node、Python 或手动启动 CMD。
2. 首次打开为空配置。在“基础资料”填写当前运营，导入账号表或新增账号，填剪辑师代号、KOC、素材所在日期目录。
3. 选择自己的文案 Excel，前三列为“文案编号、文案内容、是否启用”；填写并保存账号与文案资料。
4. 逐个账号打开登录，扫码后点击核对并保存。
5. 扫描预览，核对视频、账号、完整文案后发布。启动客户端不会自动发布。
6. 明确获得平台投稿回执后自动归档到素材目录中的“已发_KOC”。结果不明不重发，归档失败只补归档。

刷新不会丢失当前窗口会话。重复点击客户端会唤起原窗口。关闭时若正在工作，会提示等待当前操作结束；不要强制结束进程。

## 数据与升级

默认资料位于 `%APPDATA%/douyin-multi-account-demo/`（可通过 Electron 的 userData 路径核实），配置 `config.json`、页面适配 `profile.json`、历史及登录态在 `data/`。
安装包不带开发机配置、登录态、视频、历史。新版本首次初始化不会覆盖已有配置。备份必须在客户端完全退出后进行；登录态属于敏感本机资料，不应放进公共共享盘。
本版不自动联网更新。升级时结束发布、退出客户端、安装新版。安装器尚未配置发布者代码签名，适合内部试点，正式签名发行需另行配置。

## 开发与构建

- `npm run desktop`：打开桌面开发入口。
- `npm run desktop:build`：准备 Python 标准库与 Chromium 后构建 Windows x64 安装包。
- `node scripts/verify-desktop-package.mjs`：验证随包 Excel 与浏览器依赖。
- `node --test tests/browser/desktop-smoke.test.mjs`：临时空数据的桌面测试。

构建机需要 Python 3.10+、安装好的 Playwright Chromium 与 Electron。客户机器不需要这些开发依赖。构建产物使用白名单，仅包含 src、生产 npm 依赖、运行时及许可证。
